# 🚀 Hospedando o Onboarding Online

## Opção 1: GitHub Pages (Recomendado - Gratuito)

### Passo 1: Criar repositório no GitHub
1. Vá para https://github.com/new
2. Nome: `smiller-onboarding`
3. Descrição: "Onboarding interativo para CX Smiller"
4. Marque "Public"
5. Clique em "Create repository"

### Passo 2: Upload dos arquivos
1. Na página do repositório, clique em "Add file" > "Upload files"
2. Arraste o arquivo `onboarding_smiller_cx.html` para a caixa
3. Clique em "Commit changes"

### Passo 3: Ativar GitHub Pages
1. Vá para "Settings" > "Pages"
2. Em "Source", selecione "main" branch
3. Clique em "Save"
4. A página estará disponível em: `https://seu-usuario.github.io/smiller-onboarding/`

---

## Opção 2: Vercel (Muito fácil)

### Passo 1: Conectar GitHub ao Vercel
1. Vá para https://vercel.com
2. Clique em "Sign up with GitHub"
3. Autorize o Vercel

### Passo 2: Deploy
1. Após fazer upload no GitHub (Opção 1), Vercel detecta automaticamente
2. Ou vá para https://vercel.com/new e selecione seu repositório
3. Clique em "Deploy"
4. URL será: `https://smiller-onboarding.vercel.app`

---

## Opção 3: Netlify (Também gratuito)

### Passo 1
1. Vá para https://netlify.com
2. Clique em "Sign up with GitHub"

### Passo 2
1. Clique em "New site from Git"
2. Selecione seu repositório
3. Deploy automático

---

## 🔐 Usando o Painel de Admin

### Login
- Clique no botão **⚙️** no canto inferior direito
- Senha: `@Smiller123`

### Funcionalidades
- **Fazer Backup**: Baixa o arquivo HTML completo
- **Restaurar**: Carrega um backup anterior
- **Resetar**: Volta ao original

### ⚡ Auto-salvamento
- As edições são salvas automaticamente no navegador
- Compartilhe a URL com seu time
- Todos verão as atualizações em tempo real
